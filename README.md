# s21_matrix: библиотека матричных операций на C

Статическая библиотека `s21_matrix.a` для работы с числовыми матрицами: создание и удаление, сравнение, арифметика, транспонирование, определитель, матрица алгебраических дополнений и обратная матрица. Все операции возвращают код ошибки, а управление памятью проверено тестами, включая сценарии с отказом выделения памяти.

```c
s21_matrix a, inv;
s21_create_matrix(3, 3, &a);
// заполняем: [2 5 7; 6 3 4; 5 -2 -3]

double det;
s21_determinant(&a, &det);           // -1
s21_inverse_matrix(&a, &inv);        // inv = [1 -1 1; -38 41 -34; 27 -29 24]

s21_remove_matrix(&a);
s21_remove_matrix(&inv);
```

## Структура данных

```c
typedef struct matrix_struct {
  double **matrix;
  int rows;
  int columns;
} s21_matrix;
```

## Функции

Все операции, кроме сравнения, возвращают код: `0` — OK, `1` — некорректная матрица, `2` — ошибка вычисления (несовпадающие размеры, матрица, для которой операция невозможна, `NaN` / `∞` в элементах).

| Функция | Что делает |
| ------- | ---------- |
| `s21_create_matrix(rows, columns, *result)` | создаёт матрицу, заполненную нулями |
| `s21_remove_matrix(*A)` | освобождает память |
| `s21_eq_matrix(*A, *B)` | сравнение с допуском `1e-7`; возвращает `SUCCESS` (1) или `FAILURE` (0) |
| `s21_sum_matrix`, `s21_sub_matrix` | сложение и вычитание матриц одного размера |
| `s21_mult_number(*A, number, *result)` | умножение на число |
| `s21_mult_matrix(*A, *B, *result)` | произведение матриц (`A: m×k`, `B: k×n`) |
| `s21_transpose` | транспонирование |
| `s21_calc_complements` | матрица алгебраических дополнений |
| `s21_determinant(*A, *result)` | определитель квадратной матрицы |
| `s21_inverse_matrix` | обратная матрица (код `2`, если определитель равен нулю) |

## Как это устроено

- **Определитель** считается рекурсивным разложением по первой строке через миноры (`s21_get_minor`). Для матриц 1×1 и 2×2 используются прямые формулы.
- **Обратная матрица** строится по формуле `A⁻¹ = (1 / |A|) · (A*)ᵀ`: определитель → матрица алгебраических дополнений → транспонирование → умножение на `1 / |A|`. Промежуточные матрицы освобождаются на каждом шаге.
- **Проверка входных данных** вынесена в небольшие inline-функции в `s21_helpers.h` (`s21_bad_matrix`, `s21_square_matrix`, `s21_not_equal_size` и т. д.), поэтому каждая функция API начинается с одинаковой короткой валидации. Сложение и вычитание делят общую реализацию `s21_sum_sub`.
- **Сравнение и точность.** Элементы сравниваются с допуском `1e-7`; значения, близкие к нулю по модулю, в определителе приводятся к `0.0`.
- Код разложен по файлам: одна функция API — один файл в `functions/`, общие вспомогательные функции — в `s21_helpers.c`.

## Сборка и тесты

Нужны `gcc`, `make` и библиотека [Check](https://libcheck.github.io/check/). Для отчёта о покрытии — `lcov`, для проверки утечек — `valgrind`, для форматирования — `clang-format`.

```bash
cd src
make                # собирает статическую библиотеку s21_matrix.a
make test           # запускает модульные тесты
make gcov_report    # HTML-отчёт о покрытии в report/index.html
make leak_check     # прогоняет тесты под valgrind
make style          # проверка стиля (Google), make format — автоформатирование
make clean
```

Подключение к своей программе:

```bash
gcc -std=c11 main.c s21_matrix.a -lm -o app
```

Флаги сборки: `-Wall -Wextra -Werror -std=c11`.

### Тестирование

Для каждой функции API есть отдельный файл с набором проверок: корректные случаи, некорректные матрицы, несовпадающие размеры, вырожденные матрицы (для обратной матрицы), свойства вида `A · A⁻¹ = E`.

Отдельная часть тестов проверяет поведение при **отказе выделения памяти**: функция `calloc` подменяется на версию, которая возвращает `NULL` на заданном по счёту вызове (`tests/alloc_mock.c`). На Linux подмена делается через линкер (`-Wl,--wrap=calloc`), на macOS — через динамическую библиотеку с `__interpose`. Так проверяется, что при частичной неудаче создания матрицы не остаётся утечек и функции возвращают ошибку.

| Показатель | Значение |
| ---------- | -------- |
| Модульные тесты (Check) | 70, все проходят |
| Покрытие строк (gcov / lcov) | 99,1 % |
| Покрытие функций | 100 % (11 из 11) |
| `valgrind` (утечки и ошибки памяти) | 0 ошибок |
